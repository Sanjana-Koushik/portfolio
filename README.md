## ✨ Features

- 🎨 **Crimson Dark Theme** — Deep black background with scarlet & maroon accents
- 💎 **Glassmorphism Cards** — Frosted glass UI components with glowing borders
- 🌊 **Smooth Animations** — Scroll-reveal effects and micro-interactions throughout
- 📱 **Fully Responsive** — Optimized for all screen sizes (mobile, tablet, desktop)
- ⚡ **Blazing Fast** — Built with Vite, loads in under 200ms
- 🔴 **Animated Background** — Floating crimson orbs with subtle grid overlay
- 🎯 **SEO Ready** — Meta tags, Open Graph, semantic HTML

## 🚀 Run Locally

```bash
# 1. Clone the repo
git clone https://github.com/Sanjana-Koushik/portfolio.git

# 2. Navigate into the project
cd portfolio

# 3. Install dependencies
npm install

# 4. Start the dev server
npm run dev
```

Open **[http://localhost:5173](http://localhost:5173)** in your browser.
